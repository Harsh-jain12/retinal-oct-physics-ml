# v6 summary: image-level ROM and the hybrid model

Five findings. Every number is read from the JSON file named after it (all in `results/v6/`).

1. **Eigen-retinas carry less signal than the physics features.** On OCTID CSR/DR/MH, POD coefficients of the flattened image alone reach 0.696 balanced accuracy vs 0.872 for v5; adding them to v5 changes it by +0.015 [-0.010, +0.041], p = 0.141 (`image_pod_octid_dis750.json`). No other task gains (`image_pod_<task>.json`).
2. **A healthy-only POD flags disease without labels.** The residual e(x) (r = 25) separates NORMAL from ABNORMAL with AUROC 0.700 on Kermany, 0.696 on OCTDL and 0.691 from Kermany-healthy to OCTDL (`residual_auroc.json`), and its residual maps localise the departure. As a feature it adds +0.011 [+0.000, +0.027], p = 0.049 on OCTID (`residual_clf.json`).
3. **The hybrid narrows but does not clearly close the gap to the CNN.** On OCTID CSR/DR/MH the DINOv2-S hybrid reaches 0.899 [0.864, 0.933] vs 0.935 [0.905, 0.961] for the fine-tuned ResNet-18 on the same folds; difference -0.036 [-0.078, +0.004], p = 0.965, so the paired CI includes zero (`hybrid_octid_dis750.json`, `cnn_octid_dis750.json`). It beats v5 by +0.025 [-0.004, +0.054], p = 0.045. Its top permutation-importance group is "physics: NDT (pulse-echo)" and 4 of the top 5 groups are physics features (`hybrid_importance.json`).
4. **The CNN does not look where the physics looks.** Grad-CAM mass by anatomical band vs the physics model's per-band importance: Spearman ρ = -0.22 (p = 0.48) over 12 band × class cells (`gradcam_octid_dis750.json`); the CNN puts most attention in the choroid band.
5. **A new scanner is still the hard case.** Kermany → OCTDL best configuration: v6 hybrid (DINOv2-S + physics) | none | TTA = 0.729, DME recall 0.63 (`cross.json`), far below the fine-tuned CNN's 0.925 (`cnn_kermany_to_octdl.json`). Healthy-reference calibration raises DME recall but costs AMD recall and lowers balanced accuracy. Conformal triage on the hybrid keeps ABNORMAL coverage at 0.951 for a 0.95 target on OCTDL (`conformal.json`).
